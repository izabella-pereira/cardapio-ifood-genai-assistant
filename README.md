# cardapio-ifood-genai-assistant
Olá! Desenvolvi um projeto exclusivo para o programa de estágio GenAI do iFood. Trata-se de um Assistente de Cardápio Inteligente integrado à API do Google Gemini, utilizando engenharia de prompt para criar sugestões personalizadas de delivery no tom de voz da marca. Código-fonte no GitHub: github.com | Aplicação rodando ao vivo (Deploy): github.io
